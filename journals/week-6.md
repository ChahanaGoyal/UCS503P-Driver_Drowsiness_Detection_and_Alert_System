# Week 6: EAR/MAR Integration and Drowsiness Detection

## Objective
The objective was to connect the facial measurements and detection logic with the Android monitoring application.

## Work Completed
- Worked on displaying the calculated EAR and MAR values in the monitoring interface.
- Connected the eye-closure detection logic to the monitoring workflow.
- Worked on detecting drowsiness using the selected EAR threshold and consecutive-frame condition.
- Reviewed the monitoring screen and its detection status display.
- Identified the remaining work required to connect all application components.

## Challenges / Observations
The main challenge is ensuring that the camera, facial measurements, detection logic and user interface work together consistently.

## Learning
Learned about integrating detection logic with a mobile application and the importance of testing the complete system rather than individual components alone.

## Week 6 Outcome
The application has progressed to camera-based monitoring, with EAR/MAR values and drowsiness detection available. Full integration, alerts, dashboard development and further testing remain to be completed.
