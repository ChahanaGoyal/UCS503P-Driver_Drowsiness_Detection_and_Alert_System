# Week 8: Dashboard Development

**Objective:** To develop a dashboard for monitoring and presenting real-time drowsiness detection results.

**Work Completed:**

- Built the monitoring dashboard with Kotlin and Jetpack Compose.
- Integrated the camera feed with the drowsiness analysis component.
- Displayed **Awake** and **Drowsy/Sleepy** status updates according to detected eye conditions.
- Presented EAR, MAR, eye-closure duration, and event-count information on the dashboard.

**Challenges / Observations:**

- Keeping the dashboard display synchronized with live detection results.
- Alert generation remains to be implemented.

**Week Outcome:** The integrated dashboard displayed the driver's current status along with live monitoring measurements.
