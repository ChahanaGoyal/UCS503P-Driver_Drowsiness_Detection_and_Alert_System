# Week 7: Dashboard Development

**Objective:** To create a monitoring dashboard that displays live drowsiness detection results.

**Work Completed:**

- Developed the dashboard interface using Kotlin and Jetpack Compose.
- Connected camera monitoring with the drowsiness analysis logic.
- Added a live status display for **Awake** and **Drowsy/Sleepy** states based on eye conditions.
- Included displays for EAR, MAR, eye-closure duration, and event counts.

**Challenges / Observations:**

- Synchronizing incoming detection results with the dashboard interface.
- Alert generation has not yet been implemented.

**Week Outcome:** The dashboard was connected to the analysis logic to show the driver's current state and monitoring measurements.
