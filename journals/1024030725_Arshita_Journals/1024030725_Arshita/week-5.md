# Week 5: Camera and Face Detection Integration

## Objective
This week focused on connecting the device camera and starting facial landmark detection integration.

## Work Completed
- Included the CameraX dependencies and required camera permissions.
- Added a front-camera preview to the monitoring screen.
- Configured image analysis for processing camera frames.
- Included the MediaPipe Face Landmarker dependency and its model.
- Built a helper class to initialise MediaPipe and process frames from the camera.

## Challenges / Observations
A native-library loading error appeared when monitoring was started during integration, requiring further debugging and compatibility checks.

## Learning
Understood how camera access, image processing and facial landmark detection fit together in an Android app.

## Week 5 Outcome
The camera-processing pipeline and initial MediaPipe setup were established as a foundation for real-time detection.
