# Week 1: Project Understanding

## Objective
This week focused on understanding the Driver Drowsiness Detection project, its purpose and the key features it requires.

## Work Completed
- Explored how eye and mouth movements can indicate driver drowsiness.
- Discussed key features such as eye-closure detection, yawning detection and alerts.
- Studied the use of computer vision and facial features in the proposed system.
- Outlined the basic workflow for the project.

## Challenges / Observations
An important challenge was understanding how facial movements can reliably indicate signs of drowsiness.

## Learning
Understood the role of eye and mouth movements in identifying possible driver fatigue.

## Week 1 Outcome
The project requirements and the basic approach to drowsiness detection became clear.
