# Week 4: Android Application Development

## Objective
The goal was to begin building the mobile application and set up its initial user interface.

## Work Completed
- Set up an Android project in Android Studio using Kotlin.
- Built the home screen with Jetpack Compose.
- Included Start Monitoring, History, Statistics and Settings buttons.
- Designed an initial monitoring screen with placeholders for EAR, MAR and detection status.
- Added basic navigation between the home and monitoring screens.

## Challenges / Observations
The interface was developed first; camera processing and detection functionality were still to be integrated.

## Learning
Gained an understanding of Android development, Jetpack Compose and navigation between screens.

## Week 4 Outcome
The initial app interface was finished, with basic screen navigation functioning.
