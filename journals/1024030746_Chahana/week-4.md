# Week 4: Android Application Development

## Objective
The objective was to start developing the mobile application and create its basic interface.

## Work Completed
- Created the Android project using Android Studio and Kotlin.
- Used Jetpack Compose to develop the home screen.
- Added Start Monitoring, History, Statistics and Settings buttons.
- Created the initial monitoring screen with placeholders for EAR, MAR and detection status.
- Implemented basic navigation between the home screen and monitoring screen.

## Challenges / Observations
The interface was created first, while the actual camera processing and detection functionality still needed to be connected.

## Learning
Learned the basics of Android app development, Jetpack Compose and managing screen navigation.

## Week 4 Outcome
The initial application interface was completed and basic navigation was working.
