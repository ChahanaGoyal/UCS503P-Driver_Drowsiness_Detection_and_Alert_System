# **Week 7: Dashboard Development**

**Objective:** To develop the monitoring dashboard and display live drowsiness detection results.

**Work Completed:**

- Developed the dashboard using Kotlin and Jetpack Compose.
- Integrated camera monitoring with the drowsiness analysis logic.
- Implemented live status display for **Awake** and **Drowsy/Sleepy** states based on eye conditions.
- Added EAR, MAR, eye-closure duration, and event-count displays.

**Challenges / Observations:**

- Synchronizing live detection results with the dashboard interface.
- Alert generation is not yet implemented.

**Week Outcome:** The dashboard was integrated with the analysis logic to display the driver's current status and monitoring measurements.
