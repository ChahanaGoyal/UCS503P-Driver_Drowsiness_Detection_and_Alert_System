# Week 1: Project Understanding

## Objective
The objective of this week was to understand the project idea, its purpose and the main features required for Driver Drowsiness Detection.

## Work Completed
- Studied how driver drowsiness can be identified using eye and mouth movements.
- Discussed the main features, including eye-closure detection, yawning detection and alerts.
- Explored how computer vision and facial features could be used for this project.
- Planned the basic workflow of the system.

## Challenges / Observations
The main challenge was understanding how facial movements could be used to identify signs of drowsiness reliably.

## Learning
Learned about the importance of eye and mouth movements in detecting possible signs of driver fatigue.

## Week 1 Outcome
The project requirements and basic approach for detecting drowsiness were understood.
