# **Week 8: Session Summary and Statistics**

**Objective:** To implement a summary screen displaying monitoring results after a session ends.

**Work Completed:**

- Developed the session summary screen with session timestamps and monitoring duration.
- Added drowsiness and yawning counts, longest eye-closure duration, and EAR/MAR graphs.
- Implemented local storage for saving and retrieving completed sessions.
- Added navigation to view previous sessions and their summaries.

**Challenges / Observations:**

- Maintaining session data and displaying recorded results correctly.
- Automatic audio and vibration alerts remain pending.

**Week Outcome:** The application now displays live monitoring status and provides session summaries with recorded readings and statistics after monitoring stops.
